[PRJ-0339] 먼데이닷컴(monday.com) 앱 마켓 수익배분 앱 판매

업무관리 도구 먼데이닷컴 보드 안에서 쓰는 앱(AI 요약, 자동 정리 위젯 등)을 만들어 마켓에 올리고 내장 수익화 기능으로 판매. 근거: 먼데이닷컴이 2022년 앱 마켓에 내장 수익화 기능을 추가했고 2024-06 '마켓플레이스 수익배분 프로그램'을 공지함(제목만 확인, 배분율·참여 조건은 확인 못함). 실제 수익은 추정 불가. 무자본 이유: 앱 개발 플랫폼이 무료로 제공되는 것으로 보이나 확인 필요. 출처: https://developer.monday.com/apps/changelog/announcing-the-revshare-program , https://monday.com/p/press-release/monday-com-adds-built-in-monetization-solution-to-the-apps-marketplace
